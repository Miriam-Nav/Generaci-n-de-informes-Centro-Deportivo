# ️ Centro Deportivo - Sistema de Gestión

## Descripción del Proyecto
Este programa es una app que ha sido desarrollada para la administración de un **Centro Deportivo**. La aplicación permite gestionar los socios, la oferta de actividades deportivas y las reservas.

## Tecnologías Usadas
La aplicación se ha construido utilizando tecnología .NET:
* **Lenguaje:** C#.
* **Framework:** WPF (Windows Presentation Foundation) con XAML.
* **Patrón de Arquitectura:** MVVM (Model-View-ViewModel).
* **Acceso a Datos:** Repositorio para la persistencia de datos.
* **Informes:** Crystal Reports para la generación de informes.
* **Pruebas Unitarias:** MSTest para las validaciones.
* **Documentación:** DocFX para la generación de la documentación técnica.

## Instalación
Sigue estos pasos para configurar el entorno de desarrollo:
1.**Clonar el proyecto:** Descarga el repositorio o carpeta del proyecto.
2. **Requisitos:** Asegurarse de tener instalado **Visual Studio 2022** con la carga de trabajo de "Desarrollo de escritorio de .NET".
3. **Restaurar Dependencias:** Al abrir el archivo `.sln`, el IDE restaurará automáticamente los paquetes NuGet necesarios.
4. **Configuración de Base de Datos:** Verificar la cadena de conexión en el archivo de configuración para asegurar el acceso a los datos.

## Cómo ejecutar
1. Abrir la solución **CentroDeportivo.sln** en Visual Studio.
2. Establecer el proyecto View como **Proyecto de Inicio**.
3. Clic en el botón **Iniciar** para compilar y ejecutar la aplicación.
4. La ventana principal mostrará el acceso a los módulos de Socios, Actividades y Reservas.
