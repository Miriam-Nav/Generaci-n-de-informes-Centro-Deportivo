# ️ Centro Deportivo - Sistema de Gestión

## Descripción del Proyecto
Este programa es una app que ha sido desarrollada para la administración de un **Centro Deportivo**. La aplicación permite gestionar los socios, la oferta de actividades deportivas y las reservas.

## Tecnologías Usadas
La aplicación se ha construido utilizando tecnología .NET:
* **Lenguaje:** C#.
* **Framework:** WPF (Windows Presentation Foundation) con XAML.
* **Patrón de Arquitectura:** MVVM (Model-View-ViewModel).
* **Acceso a Datos:** Repositorio para la persistencia de datos.
* **Informes:** Crystal Reports para la generación de informes.
* **Pruebas Unitarias:** MSTest para las validaciones.
* **Documentación:** DocFX para la generación de la documentación técnica.

## Instalación 
Para instalar la aplicación en su sistema, hay que seguir estos pasos:

1. **Localizar el instalador:** Busca el instalador y ejecuta el archivo `setup.exe` .
2. **Asistente de instalación:** Se abrirá el asistente de Visual Studio Installer. Haz clic en "Siguiente" para continuar.
3. **Selección de ruta:** Elije la carpeta de destino.
4. **Confirmación:** Haz clic en "Instalar". Es posible que el sistema solicite permisos de administrador.
5. **Finalización:** Una vez completada la barra de progreso, haz clic en "Cerrar". El sistema habrá creado un acceso directo en el Escritorio y en el Menú Inicio.

## Cómo ejecutar
1. Haz doble clic en el icono **"Centro Deportivo"** del Escritorio.
2. La aplicación mostrará el panel principal.
